# 从原型到真实产品

1. **商品数据**：接入商家各尺码的胸、腰、肩、袖、衣长实测值，记录面料弹性和版型；在数据缺失时不输出高置信度推荐。
2. **尺码预测服务**：服务端接受经用户授权的身材、商品尺寸和偏好，返回各尺码分数、部位余量、证据和置信度；持续用真实退换货及评价数据验证。
3. **真实虚拟试穿**：单独接入图像生成或服装形变服务，传入用户照片与所选尺码的真实衣服图和尺寸；在结果上标明生成图可能与实物不同。宽松程度要由所选尺码控制。
4. **账户与隐私**：增加照片上传同意、保留期限、删除入口、加密传输和最小化储存。当前原型只有本机数据。
5. **购买与反馈**：接入真实订单并仅对已购买商品收集穿着评价，建立预测版本和评价的关联，以量化模型是否改善。
