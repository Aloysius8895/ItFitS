# From prototype to product

1. **Product data:** Import measured chest, waist, shoulder, sleeve, and length values for every merchant size. Track fabric stretch and cut. Do not claim high confidence when measurements are missing.
2. **Size prediction:** With the user's consent, send body measurements, product sizing, and fit preference to a service that returns per-size scores, ease by body zone, supporting evidence, and confidence. Validate predictions against returns and real reviews.
3. **Real virtual try-on:** Connect an image generation or garment warping service using the user's photo, the selected garment image, and the measurements for the **selected size**. Clearly identify generated images and their limits.
4. **Accounts and privacy:** Add photo consent, retention periods, deletion, encrypted transfer, and minimal storage. The current prototype keeps data on the device.
5. **Purchases and feedback:** Connect actual orders and accept fit reviews for purchased items. Link each review to the prediction version to measure improvements.
